# Agxiome Toolkits

## Summary
The `AGXIOME.Toolkits` project provides a collection of reusable utility components for the AGXIOME agent framework. It bundles third‑party libraries for PDF text extraction (UglyToad.PdfPig), image processing (SixLabors.ImageSharp), and data analysis (CsvHelper, ClosedXML, Microsoft.Data.Sqlite), enabling agents to manipulate documents, images, and tabular data through a unified API.
