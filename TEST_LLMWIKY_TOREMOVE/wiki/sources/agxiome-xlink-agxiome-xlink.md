# Agxiome XLink

## Summary
The `AGXIOME.XLink` project is a source component of the AGXIOME .NET agent framework that implements XLink (XML Linking Language) functionality. It depends on the shared library `AGXIOME.Shared` and targets .NET 10.0 with nullable reference types enabled, providing a foundation for linking and referencing resources within agent workflows.

## Key Details
- **Project File:** `AGXIOME.XLink/AGXIOME.XLink.csproj`
- **Target Framework:** `net10.0`
- **Dependencies:** `AGXIOME.Shared` (Project Reference)
- **Language Features:** `ImplicitUsings` and `Nullable` enabled
- **Role:** Provides XLink support for agent-based document or resource linking
- **Location:** Part of the broader AGXIOME framework, under the XLink subcomponent
