# AgenticChunker

## Summary
`AgenticChunker` is an intelligent text chunker that leverages an `ILLMProvider` to identify natural topic boundaries for splitting documents. It first splits text into sentence‑level candidates via `RecursiveChunker`, then sends sliding windows of those candidates to an LLM—which returns a JSON array of indices where a new chunk should begin. This “agentic” approach produces semantically coherent chunks, and it degrades gracefully to the `RecursiveChunker` fallback when no LLM is available or on LLM failure.

## Key Details
- Implements `IChunker` and supports both synchronous (`Chunk`) and async (`ChunkAsync`) entry points.
- Uses a minimal, injection‑resistant prompt: the LLM is instructed to output **only** a JSON array of integer indices, preventing document content from hijacking the boundary list.
- Sliding window size defaults to 20 candidate sentences per LLM call (`WindowSize` property).
- Candidate sentences are generated by `RecursiveChunker` with `maxTokens=30` and no overlap.
- The `Chunk` method blocks on the async implementation via `.GetAwaiter().GetResult()`; production code should prefer `ChunkAsync`.
- On LLM failure (exception or inability to parse JSON), the method returns an empty boundary set, causing graceful fallback to `RecursiveChunker` output.
- Overlap is applied by carrying the tail of the previous segment (~`overlap * 4` characters) into the current chunk.
- The `ChunkerType` property returns `ChunkerType.Agentic`.
