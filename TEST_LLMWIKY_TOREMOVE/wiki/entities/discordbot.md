# DiscordBot

## Summary
The `DiscordBot` sealed class serves as the primary bridge between AGXIOMA agents and the Discord platform. It handles incoming interactions (slash commands and pings) via the Discord HTTP Interaction API, verifies request signatures, and delegates command processing to an underlying `IAgxiomeAgent`. It also provides a method to register slash commands with Discord. Designed to work with Discord.NET or as a standalone HTTP handler.

## Key Details
- **Namespace**: `AGXIOME.Interfaces.Discord`
- **Sealed class** with dependencies: `applicationId`, `botToken`, `publicKey`, and an `IAgxiomeAgent` instance.
- Uses an internal `HttpClient` with a `Bot` authorization header to communicate with Discord API v10 (`https://discord.com/api/v10`).
- **`VerifySignature`** – Placeholder Ed25519 signature verification using the Discord public key (production implementation required).
- **`ProcessInteractionAsync`** – Parses incoming JSON interaction payloads:
  - **Type 1 (PING)** → returns a `{ "type": 1 }` PONG response.
  - **Type 2 (APPLICATION_COMMAND)** → extracts command name, user ID, and options, builds a prompt, calls `_agent.RunAsync(new AgentRequest(prompt))`, and returns a channel message with the agent’s content.
- **`RegisterSlashCommandAsync`** – Registers a global slash command via POST to applications/{id}/commands.
- Built on `System.Text.Json` for JSON serialization/deserialization.
- Supports cancellation tokens throughout.
