# DiscoveredAgentEntry

## Summary
`DiscoveredAgentEntry` is an immutable record that represents a dynamic agent discovered via hot‑folder or generated by an LLM, stored in the agent registry. It captures the agent's identity, file metadata, source hash, and lifecycle status (`AgentEntryStatus`), enabling the runtime to track compilation state and detect source changes.

## Key Details
- Sealed record with positional parameters: `AgentId`, `Description`, `FilePath`, `SourceHash`, `Status`, `DiscoveredAt`, and optional `LastError`.
- `AgentEntryStatus` enum defines lifecycle states: `Discovered`, `Compiling`, `Compiled`, `Failed`, `NeedsRecompile`.
- `WithStatus(AgentEntryStatus newStatus, string? error = null)` returns a new instance with updated `Status` and `LastError` (non‑mutating copy).
- `SourceHash` is used to detect file modifications and trigger `NeedsRecompile` status.
- `LastError` populates on `Failed` or other error conditions, providing compilation failure details.
- `FilePath` points to the original `.cs` source file on disk.
