# Art. 928 Codice Civile - Pubblicazione del ritrovamento

## Summary

Art. 928 of the Italian Civil Code establishes the procedural obligation for the mayor to publicise the delivery of a found object (consegna ex [[art927]]). The publication must be made by posting a notice on the municipal bulletin board (albo pretorio) for two consecutive Sundays, each posting remaining affixed for three continuous days. This rule implements the transparency requirement of the invention system, allowing the rightful owner a reasonable opportunity to reclaim the item before it may be awarded to the finder or transferred to the State.

## Key Details

- **Official reference**: Art. 928 Codice Civile (Libro III, Titolo II, Capo III, Sezione I)
- **Subject**: Publication of the finding of movable objects
- **Method**: Notice posted on the municipal bulletin board (albo pretorio)
- **Duration**: Must be displayed for two consecutive Sundays, each for three days (i.e., affixed for three days each time)
- **Purpose**: Inform the public so the legitimate owner can assert ownership before the item is awarded to the finder (under rules of invention)
- **Trigger**: The delivery of the found object to the mayor (art. 927 c.c.)
- **Subsequent steps**: If the owner does not claim the item within one year, the finder acquires ownership or, if the finder does not, the item passes to the State (artt. 929, 930 c.c.)
- **Historical context**: Article unchanged from the original 1942 code
