## Post-MVP: X402 (Differito)

X402 is the next-generation protocol for agent-to-agent communication across organizational boundaries. It extends the A2A protocol with:

- **Federation**: Cross-org agent discovery and routing
- **Capability Advertisement**: Agents publish supported skills
- **Trust Verification**: Cryptographic proof of agent identity
- **Payment/Usage Tracking**: Per-call metering and settlement
- **Fault-Tolerant Delivery**: At-least-once semantics for agent messages

### Timeline

- **Q3 2026**: X402 specification draft, reference implementation
- **Q4 2026**: Integration with AGXIOME A2A protocol
- **Q1 2027**: Public beta with federation support
